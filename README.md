# Viora UI Component Preview

A minimal showcase of the UI components used across Viora templates. Built on [shadcn/ui](https://ui.shadcn.com/) with custom styling and component enhancements.

[**Live Preview**](https://viora-studio.github.io/template-preview/)

## Available templates

The same design system is available in two frameworks:

| Template | Framework |
| --- | --- |
| [Vite Template](https://github.com/viora-studio/vite-template) | React + Vite |
| [Next.js Template](https://github.com/viora-studio/nextjs-template) | React + Next.js |

Both templates share the same visual language and component approach, adapted to their respective frameworks.

## Run locally

```bash
pnpm install
pnpm dev
```
